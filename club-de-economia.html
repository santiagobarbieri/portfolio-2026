Club de Economía — UTDT

Universidad Torcuato Di Tella · 2026

Marca y sistema gráfico para el relanzamiento del Club de Economía. Las diagonales conectan una identidad propia con la vida universitaria.

Paleta

Celeste para distinguir al club; gris y negro para sus versiones clara y oscura.

Valores de referencia muestreados de las piezas.

  • Celeste #42AEBD
  • Gris claro #D9D9D9
  • Negro #000000

Síntesis

La flecha ascendente dio paso a las diagonales: menos elementos para conservar el movimiento y el vínculo con la universidad.

Sistema de marca

Una marca que combina isotipo y logotipo, con aplicaciones a una tinta.

Plantillas para redes

Un sistema para posts e historias. Las piezas conservan campos de ejemplo.

Trama

Las diagonales del símbolo se extienden a una trama para redes.
